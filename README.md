# EBA Fizik Modelleme ve Simülasyon Portalı (The Skeld)

Bu proje doğrudan GitHub Pages veya Node.js üzerinde çalıştırılabilir.

## GitHub Pages ile Ücretsiz Site Olarak Yayınlama (2 Dakika)
1. GitHub'da yeni bir repository (depo) oluşturun.
2. Bu klasördeki tüm dosyaları o depoya yükleyin (Commit & Push).
3. Deponuzun **Settings (Ayarlar) -> Pages** sekmesine gidin.
4. **Branch** kısmından `main` (veya `master`) ve `/ (root)` seçip **Save** butonuna basın.
5. GitHub size özel bir site bağlantısı verecektir (Örn: `https://kullaniciadiniz.github.io/depo-adi/`).
6. Okulda veya evde doğrudan bu bağlantıyı tarayıcınızda açıp **FREEPLAY** modunda oynayabilirsiniz!

## Okul / MEB Panik Modu (EBA Kamuflajı):
- Oyun esnasında klavyeden **F9** tuşuna basıldığında ekran anında 11. Sınıf Fizik ders notları ve MEB EBA Ders Akışı ekranına dönüşür.
- Sayfa başlığı ve sekme simgesi EBA olarak değişir, sesler otomatik sessize alınır.
- Tekrar **F9** basılarak oyuna dönülebilir.
